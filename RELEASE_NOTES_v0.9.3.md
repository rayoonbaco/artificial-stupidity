This prerelease adds a frozen, CPU-only portability test in a materially different domain: bounded legislative-publication claims from Bill X-Ray. The protected AI-research gate, H100 evidence, adversarial receipts, and Bill X-Ray code are unchanged.

- BX02 contradicted mandate-and-funding overclaim: expected REJECT, observed **REJECT**.
